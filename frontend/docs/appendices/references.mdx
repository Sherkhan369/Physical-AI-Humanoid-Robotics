# References

This section provides a curated list of resources, including official documentation, research papers, and articles, that were referenced or are highly recommended for further reading to deepen your understanding of the concepts presented in this textbook.

---

## 1. ROS 2 Documentation

-   **Official ROS 2 Documentation**: [https://docs.ros.org/en/humble/](https://docs.ros.org/en/humble/)
    -   Comprehensive guides, tutorials, and API references for ROS 2 Humble Hawksbill.
-   **ROS 2 Tutorials**: [https://docs.ros.org/en/humble/Tutorials.html](https://docs.ros.org/en/humble/Tutorials.html)
    -   Step-by-step guides covering fundamental ROS 2 concepts.

## 2. Gazebo Documentation

-   **Gazebo Garden Documentation**: [http://gazebosim.org/docs/garden/](http://gazebosim.org/docs/garden/)
    -   Official documentation for Gazebo Garden, including installation and usage.
-   **Gazebo ROS Integration**: [https://github.com/ros-gbp/gazebo_ros_pkgs](https://github.com/ros-gbp/gazebo_ros_pkgs)
    -   Packages for integrating Gazebo with ROS 2.

## 3. Unity Documentation

-   **Unity Manual**: [https://docs.unity3d.com/Manual/index.html](https://docs.unity3d.com/Manual/index.html)
    -   The official Unity documentation covering all aspects of the editor and engine.
-   **Unity Inverse Kinematics (IK)**: [https://docs.unity3d.com/Manual/InverseKinematics.html](https://docs.unity3d.com/Manual/InverseKinematics.html)
    -   Detailed explanation of Unity's built-in IK system.
-   **Unity Rigidbody Component**: [https://docs.unity3d.com/Manual/class-Rigidbody.html](https://docs.unity3d.com/Manual/class-Rigidbody.html)
    -   Information on Unity's physics component for handling rigid body dynamics.

## 4. Unity Robotics Hub

-   **Unity Robotics Hub GitHub**: [https://github.com/Unity-Technologies/Unity-Robotics-Hub](https://github.com/Unity-Technologies/Unity-Robotics-Hub)
    -   Repository containing tools and tutorials for integrating Unity with ROS and robotics workflows.
-   **URDF Importer Package**: [https://github.com/Unity-Technologies/Unity-Robotics-Hub/tree/main/tutorials/ros_unity_integration/urdf_importer](https://github.com/Unity-Technologies/Unity-Robotics-Hub/tree/main/tutorials/ros_unity_integration/urdf_importer)
    -   Package for importing URDF/SDF models into Unity.

## 5. NVIDIA Isaac Sim & Isaac ROS

-   **NVIDIA Isaac Sim Documentation**: [https://docs.omniverse.nvidia.com/app_isaacsim/app_isaacsim/overview.html](https://docs.omniverse.nvidia.com/app_isaacsim/app_isaacsim/overview.html)
    -   Official documentation for NVIDIA Isaac Sim, covering installation, features, and development guides.
-   **NVIDIA Isaac ROS Documentation**: [https://docs.nvidia.com/isaac/isaac_ros/index.html](https://docs.nvidia.com/isaac/isaac_ros/index.html)
    -   Documentation for Isaac ROS packages, including GPU-accelerated perception and processing.
-   **NVIDIA Omniverse Launcher**: [https://www.nvidia.com/en-us/omniverse/download/](https://www.nvidia.com/en-us/omniverse/download/)
    -   Download page for the Omniverse Launcher to install Isaac Sim.

## 6. Reinforcement Learning Resources

-   **Stable Baselines3**: [https://stable-baselines3.readthedocs.io/en/master/](https://stable-baselines3.readthedocs.io/en/master/)
    -   A set of reliable implementations of reinforcement learning algorithms in PyTorch.
-   **Deep RL Homework (UC Berkeley)**: [http://rail.eecs.berkeley.edu/deeprlcourse/](http://rail.eecs.berkeley.edu/deeprlcourse/)
    -   Course materials and lectures on deep reinforcement learning.

## 7. Research Papers & Further Reading

-   **Humanoid Balance Control**: \[Example Paper\] Siciliano, B., & Khatib, O. (Eds.). (2008). *Springer Handbook of Robotics*. Springer.
    -   (Search for recent papers on humanoid balance control, e.g., using terms like "humanoid bipedal walking control", "zero moment point", "capture point method".)
-   **SLAM Algorithms**: Durrant-Whyte, H., & Bailey, T. (2006). Simultaneous localization and mapping: part I. *Robotics and Automation Magazine, 13*(2), 100-110.
    -   (Search for recent SLAM papers, e.g., "Cartographer ROS", "RTAB-Map ROS".)
-   **End-to-End Learning for Robotics**: Levine, S., et al. (2016). End-to-end training of deep visuomotor policies. *Journal of Machine Learning Research, 17*(39), 1-40.
    -   (Relevant to VLA and integrated learning approaches.)
